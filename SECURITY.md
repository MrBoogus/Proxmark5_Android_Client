# Security Policy & Responsible Use Notice

## Legal & Ethical Use Only

**Proxmark5 Android Client** is an open-source research, diagnostics, and hardware companion tool for the **Proxmark5**.

- You may **only** use this software and associated hardware on RFID/NFC cards, badges, transponders, and access-control systems that **you personally own** or for which you have **explicit, written authorization** from the owner to test.
- Unauthorized reading, cloning, emulation, or modification of access credentials may violate local, national, or international laws. The authors and contributors assume no liability for misuse of this software.

---

## Reporting a Security Vulnerability

If you discover a security vulnerability in this Android application (for example, an unintended local IPC exposure, unsafe file handling, or credential-vault leakage):

1. **Do not** open a public issue with exploit details first.
2. Open a [GitHub Security Advisory](https://github.com/MrBoogus/Proxmark5_Android_Client/security/advisories/new) on this repository (or contact `@MrBoogus` via GitHub) with:
   - Affected version / commit SHA
   - Steps to reproduce
   - Impact assessment and suggested remediation

We aim to acknowledge reports within 72 hours and publish a fix in a patch release (`v1.0.x`).

### Supported Versions

| Version | Supported |
| :--- | :---: |
| `1.0.x` (latest release / `main`) | Yes |
| `< 1.0.0` | No |
